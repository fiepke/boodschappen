# Mijn Boodschappen

Gratis PWA-boodschappenlijst voor GitHub Pages.

## Op GitHub Pages zetten

1. Maak een gratis GitHub-account als je die nog niet hebt.
2. Maak een nieuwe repository, bijvoorbeeld `boodschappen`.
3. Upload alle bestanden uit deze ZIP naar de repository.
4. Ga naar **Settings → Pages**.
5. Kies bij **Build and deployment**: `Deploy from a branch`.
6. Kies branch `main` en map `/ (root)`.
7. Klik op **Save**.
8. Na publicatie krijg je een adres zoals:
   `https://jouwnaam.github.io/boodschappen/`

Op Android/Chrome:
- Open de website.
- Kies **App installeren** of via het Chrome-menu **Toevoegen aan startscherm**.

De lijst wordt lokaal op het apparaat opgeslagen.
